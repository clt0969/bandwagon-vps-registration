## 搬瓦工注册前需要准备什么

开始之前，准备好以下信息即可：

- 一个长期使用、能够正常收信的邮箱
- 一个符合要求的登录密码
- 真实有效的姓名、地址和联系电话
- 可用于支付的方式
- 大致明确自己的用途，例如建站、开发测试、个人项目或运行轻量服务

邮箱尤其重要。注册验证邮件、订单通知、账单提醒、密码重置和客服回复都可能发送到这个邮箱。不要使用临时邮箱，也不要为了省事填写无法验证的虚假信息。

搬瓦工的服务条款要求账户资料保持真实、有效。如果姓名、地址或电话等信息无法验证，账户或服务可能受到影响。

## 下单时应该检查哪些项目

选择套餐后，不要马上点击付款。先检查购物车和产品配置。

### 1. 确认计费周期

同一个产品可能在下单页提供不同计费周期，也可能只有页面公开的周期可选。月付看起来灵活，但长期成本通常高于年付或半年付方案。

如果页面显示周期选择，建议先分别查看总价，再决定是否需要一次性支付更长周期。

### 2. 确认机房位置

不同机房到不同地区的网络表现可能不同。搬瓦工官网的 VPS 页面通常会根据产品提供可选位置，但并非每个套餐都能自由选择所有机房。

如果你已经明确服务的主要访问地区，优先检查机房选项，而不是只看 CPU 和硬盘。机房位置会影响延迟、访问速度和部分业务的稳定性。

### 3. 查看是否有额外费用

下单前检查：

- 产品价格
- 计费周期
- 是否添加了额外 IP
- 是否添加了备份或其他附加项目
- 优惠金额是否真实显示
- 最终应付金额和币种

当前官方公开价格页面显示的是美元价格。本文没有加入无法从官方页面确认的优惠码或折扣承诺。网络上经常能看到所谓“永久优惠码”，但如果结账页面没有实际减价，就不要把它当成有效优惠。

## 搬瓦工注册信息怎么填写

### 姓名怎么填

姓名应尽量与支付账户或可验证身份保持一致。不要频繁更换姓名，也不要使用明显虚假的占位文字。

如果表单要求英文或拼音，可以使用常用拼音格式。例如名字和姓氏分别填写，不要把整段姓名全部塞进一个字段。

### 地址怎么填

地址的重点是准确、稳定、可解释。没有公司信息时，`Company Name` 通常可以留空。地址字段如果不确定如何拆分，可以按街道、城市、省份和邮编分别填写。

不要为了“看起来像海外用户”而随意选择错误国家。官方条款明确要求账户使用真实有效的联系资料。

### 邮箱收不到验证邮件怎么办

可以依次检查：

1. 垃圾邮件或广告邮件文件夹。
2. 邮箱地址是否填写错误。
3. 是否等待了几分钟。
4. 注册页面是否提供重新发送验证邮件的选项。
5. 仍然无法完成时，通过官方客服工单联系支持团队。

不要反复创建多个账户来测试。这样会让后续订单核验和账单管理更麻烦。

## 付款完成后会发生什么

付款成功后，订单需要经过系统处理。服务开通后，你可以在账户后台查看 VPS，然后进入 KiwiVM 控制面板管理服务器。

官方介绍的 KiwiVM 功能包括：

- 开机、关机和重启
- 重装操作系统
- 使用紧急控制台
- 配置反向 DNS
- 迁移数据中心
- 创建和管理快照
- 查看流量和资源使用情况
- 使用 API 完成部分管理操作

需要注意的是，搬瓦工提供的是自管理 VPS。它负责基础设施、网络和服务器平台，但通常不会替你安装网站程序、配置数据库或排查应用代码问题。官方 FAQ 也说明，除非问题属于服务本身无法正常运行，否则一般不会代替用户完成安装和配置工作。

拿到 VPS 后，建议先做这几件事：

1. 确认服务器 IP 和机房位置。
2. 确认 SSH 或其他远程登录方式正常。
3. 检查系统版本和磁盘、内存、流量信息。
4. 立即更新系统软件包。
5. 修改默认登录策略并配置防火墙。
6. 再安装网站、面板、数据库或其他服务。

不要刚开通就堆一大套软件。先确认基础连接正常，后面出问题时更容易判断到底是系统、网络还是应用配置导致的。

## 续费和自动扣款要特别留意

搬瓦工官方知识库说明，系统不会直接保存信用卡或 PayPal 的支付信息，也不会像部分订阅服务那样自动从支付方式扣款。续费相关账单会根据账户中的续费状态生成；如果账户里有余额，余额可能被用于支付账单。

建议定期进入账户后台检查：

- 当前服务是否开启续费
- 下一次账单日期
- 续费金额
- 账户余额
- 服务是否因未付款进入暂停状态

如果不准备继续使用，应及时关闭续费或取消服务。不要只卸载网站文件，却忘记 VPS 本身仍然处于有效状态。
